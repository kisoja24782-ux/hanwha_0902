# 파이썬 기초 문법 핵심 정리

본 문서는 실무 백엔드 프로그래밍 교육 과정에서 작성된 코드를 바탕으로 파이썬의 주요 문법과 개념을 정리한 문서입니다.

## 1. 변수와 자료형 (Variables & Data Types)
*   **변수 할당:** `x = 5`, `y = 'john'` 처럼 숫자나 문자열을 변수에 저장할 수 있습니다. 작은따옴표(`'`)와 큰따옴표(`"`)는 모두 문자열을 나타내는 데 사용됩니다.
*   **형 변환 (Type Casting):** 
    *   `str(3)`: 숫자 3을 문자열 "3"으로 변환합니다.
    *   `int(3)`: 정수형으로 변환합니다.
    *   `float(3)`: 소수점이 있는 실수형으로 변환합니다.
*   **문자열 연산 및 출력:**
    *   쉼표(`,`) 사용: `print(x, y, z)`는 각 변수 사이에 띄어쓰기를 자동으로 삽입하여 출력합니다.
    *   더하기(`+`) 사용: `print(x + y + z)`는 공백 없이 문자열을 하나로 이어 붙입니다.
    *   문자열과 숫자를 더할 때는 반드시 `str(x) + y`와 같이 숫자를 문자열로 형 변환해야 오류가 발생하지 않습니다.
    *   문자열 곱셈: `print("=" * 40)`과 같이 곱하기를 사용하면 문자열을 해당 횟수만큼 반복해서 출력할 수 있어 시각적인 구분선을 만들 때 유용합니다.

## 2. 자료구조와 반복문 (Data Structures & Loops)
*   **리스트 (List):** `AIlist = ["파이썬 기본 문법", "클래스", "데코레이터", "예외처리", "로깅"]`과 같이 대괄호(`[]`) 안에 여러 개의 데이터를 순서대로 담아 관리합니다.
*   **for 반복문:**
    *   **리스트 순회:** `for x in AIlist:` 구문을 사용하면 리스트 안에 있는 요소들을 처음부터 끝까지 하나씩 꺼내어 반복적인 작업을 수행할 수 있습니다.
    *   **range() 함수:** `for y in range(10):`은 0부터 9까지 총 10번 반복하게 만들어 줍니다.
*   **출력 제어 (end 속성):** `print(y, end=" ")`와 같이 `end` 값을 지정하면 기본값인 '줄바꿈' 대신 설정한 문자(공백 등)가 출력되어 한 줄로 이어서 출력할 수 있습니다.

## 3. 함수 (Functions)
함수는 자주 반복되는 코드를 묶어두고 필요할 때마다 이름을 불러서 사용하는 기능입니다.
*   **함수 정의:** `def` 키워드를 사용하여 정의합니다. (예: `def myfunc():`)
*   **반환값 (Return):** 연산이 완료된 결과값을 함수 밖으로 내보낼 때는 `return`을 사용합니다.
*   **구현 예시:**
    *   사칙연산 함수: `add(a, b)`, `sub(a, b)`, `mul(a, b)`, `div(a, b)`
    *   온도 변환 함수: 화씨(F)를 섭씨(C)로 변환하는 공식 `return (f - 32) * 5 / 9`

## 4. 모듈 임포트와 환경 설정 (Modules & Environments)
*   **패키지/모듈 불러오기:** 
    *   `import numpy as np`: 외부 라이브러리인 numpy를 불러와서 `np`라는 짧은 별칭으로 사용합니다.
    *   `from re import MULTILINE`: `re` 모듈에서 `MULTILINE`이라는 특정 기능만 콕 집어서 불러옵니다.
