# FastAPI 핵심 개념 정리 노트

## 1. FastAPI 기본 구조
* `fastapi` 패키지에서 `FastAPI` 도구를 불러와서 웹 서버 객체(`app = FastAPI()`)를 생성합니다 [cite: 2].
* `@app.get("/")`와 같은 데코레이터를 이정표로 사용하여 목적지(경로)를 지정합니다 [cite: 2].
* 지정한 주소로 접속했을 때 실행될 함수를 정의하고 딕셔너리 등의 형태로 반환값을 지정하면, 서버가 해당 데이터를 손님에게 넘겨줍니다 [cite: 2].

## 2. 경로 매개변수 (Path Parameter)
* URL 경로에 중괄호 `{}`를 사용하여 동적인 값을 변수로 받을 수 있습니다 (예: `/items/{item_id}`) [cite: 2].
* **경로 순서의 중요성**: 고정된 주소(예: `/users/me`)를 처리하는 코드는 반드시 동적인 변수를 받는 주소(예: `/users/{user_id}`)보다 상단에 작성해야 서버가 혼동하지 않고 정확히 응답합니다 [cite: 1].
* **Enum을 활용한 입력값 제한**: `Enum` 클래스(열거형)를 상속받아 허용할 고정된 값(예: `alexnet`, `resnet`, `lenet`)을 미리 정의해 둘 수 있습니다 [cite: 1]. 지정되지 않은 값이 주소창으로 들어올 경우, 서버가 알아서 차단하고 에러 메시지를 내보냅니다 [cite: 1].

## 3. 쿼리 매개변수 (Query Parameter)
* URL의 `?` 뒤에 추가로 붙여 보내는 선택적 정보로, 파이썬 함수의 매개변수에 선언해 두면 자동으로 쿼리 매개변수로 인식됩니다 (예: `q`, `skip`, `limit`) [cite: 1, 2].
* `skip`이나 `limit` 같은 변수를 통해 데이터베이스나 리스트에서 일부 데이터만 잘라올 때(예: `fake_items_db[skip : skip + limit]`) 유용하게 쓰입니다 [cite: 1].
* 타입 힌트에 `str | None = None`처럼 작성하면 값을 입력하지 않아도 에러가 나지 않는 '선택적(Optional) 매개변수'를 만들 수 있습니다 [cite: 2].

## 4. 데이터 요청과 검증 (Request Body & Pydantic)
* 서버로 데이터를 새로 등록(POST)하거나 수정(PUT)할 때는 단순히 주소창을 쓰지 않고 데이터 본문(Request Body)을 전송합니다 [cite: 3, 4].
* `pydantic` 패키지의 `BaseModel`을 상속받는 클래스를 만들어, 데이터가 들어올 엄격한 양식(예: `name`, `price`, `tax` 등 필수/선택 여부 및 자료형)을 정의합니다 [cite: 3, 4].
* 새로운 데이터를 생성하는 `@app.post("/items")` 창구나 수정하는 `@app.put("/items/{item_id}")` 창구에서 이 양식 클래스(예: `item: Item`)를 매개변수로 지정하면, FastAPI가 전송된 데이터가 규칙에 맞는지 자동으로 검증해 줍니다 [cite: 3, 4].
