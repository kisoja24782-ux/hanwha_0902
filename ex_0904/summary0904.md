# 파이썬 Numpy 배열 및 Streamlit 인터랙티브 UI 개념 정리

본 문서는 파이썬의 Numpy 라이브러리를 활용한 다차원 배열(Array) 처리 방법과 Streamlit을 이용한 반응형(Interactive) 웹 대시보드 구축 개념을 정리한 마크다운 문서입니다.

## 1. 문자열 포맷팅 및 처리
*   **f-string 포맷팅:** `f"The price is {price:.2f} dollars"` 처럼 중괄호 `{}` 안에 변수를 넣고, `:.2f`를 추가하여 소수점 둘째 자리까지 깔끔하게 출력할 수 있습니다.
*   **문자열 조작 내장 함수:**
    *   `center(20)`: 지정한 길이(20) 안에서 문자열을 가운데 정렬합니다.
    *   `find("단어")`: 특정 단어가 시작되는 인덱스를 찾습니다.
    *   `lstrip()`, `rstrip()`, `strip()`: 각각 왼쪽, 오른쪽, 양쪽의 공백을 제거합니다.
    *   `maketrans` & `translate`: `str.maketrans("S", "P")`로 변환표를 만들고, `translate()`를 적용해 문자열 내의 특정 문자를 일괄 치환합니다.

## 2. Numpy 다차원 배열 (Arrays)
`import numpy as np`를 통해 빠르고 강력한 수치 계산용 라이브러리를 사용합니다.
*   **배열 생성 및 차원 확인:**
    *   `np.array([1, 2, 3])`: 리스트나 튜플을 Numpy 배열로 변환합니다.
    *   `ndim`: `arr3.ndim`을 출력하면 해당 배열이 몇 차원(1차원, 2차원, 3차원 등)인지 알려줍니다.
*   **인덱싱 (Indexing):** 
    *   `arr5[1, 4]`: 2차원 배열에서 두 번째 행(인덱스 1)의 다섯 번째 열(인덱스 4) 요소를 정확히 찾아옵니다. (면, 행, 열 순서)
    *   음수 인덱스를 사용(`arr7[1, -1]`)하면 뒤에서부터 요소를 역순으로 찾아옵니다.
*   **슬라이싱 (Slicing):**
    *   `arr8[1:5]`: 인덱스 1부터 4(5-1)까지 잘라냅니다.
    *   `arr10[1:5:2]`: 인덱스 1부터 4까지 범위에서 **2칸씩 건너뛰며(Step)** 추출합니다.
    *   `arr14[0:2, 1:4]`: 다차원 배열에서 행(0~1)과 열(1~3) 범위를 동시에 지정하여 새로운 2차원 배열로 잘라낼 수 있습니다.

## 3. 객체지향 기초 및 상속
*   `class Student(Person):` 과 같이 괄호 안에 부모 클래스 이름을 넣어 상속을 받습니다. 
*   `Person.__init__(self, fname, lname)`를 호출하여 부모 클래스의 초기화(생성자) 로직을 그대로 재사용할 수 있습니다.

## 4. Streamlit 인터랙티브 UI 컴포넌트
Streamlit을 사용하면 복잡한 웹 지식 없이도 파이썬 코드만으로 클릭하고 반응하는 대시보드를 만들 수 있습니다.
*   **버튼 이벤트 (`st.button`):** 
    *   `if st.button("인사!"):` 처럼 작성하면, 사용자가 버튼을 클릭했을 때만(True) 특정 코드(`st.write("반갑습니다.")`)가 실행되도록 제어할 수 있습니다.
*   **다단 레이아웃 (`st.columns`):**
    *   `left, middle, right = st.columns(3)`를 사용해 화면을 3개의 세로 열로 분할하고, 각각의 구역에 요소를 배치할 수 있습니다.
*   **메뉴 버튼 (`st.menu_button`):** 드롭다운 형태로 여러 가지 선택지(옵션) 중 하나를 고르게 합니다.
*   **별점 피드백 (`st.feedback`):** `st.feedback("stars")`를 사용하면 5점 만점의 별점 UI를 제공하고 선택된 값을 받아올 수 있습니다.
*   **알림 메시지 (`st.toast`):** `st.toast("메시지", icon="🎉")`를 사용해 화면 우측 하단에 잠깐 떴다가 사라지는 팝업 알림을 띄웁니다. `time.sleep()`과 조합하여 시간차 애니메이션을 연출할 수도 있습니다.
