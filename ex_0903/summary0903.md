# 파이썬 심화 및 시각화/웹 대시보드 개념 정리

본 문서는 파이썬의 심화 문법(클래스, 문자열 처리)과 데이터 시각화(Matplotlib), 웹 앱 구축(Streamlit)을 위한 핵심 개념을 정리한 마크다운 문서입니다.

## 1. 파이썬 기본 및 문자열 처리 (String Operations)
* **변수 타입 확인:** `type(x)`를 통해 변수의 자료형을 확인할 수 있습니다.
* **전역 변수 (Global Variable):** 함수 내부에서 `global x` 키워드를 사용하면 함수 밖의 전역 변수를 수정할 수 있습니다.
* **문자열 슬라이싱 (Slicing):** 
    * `b[2:5]`: 인덱스 2부터 4(5-1)까지 추출합니다.
    * `b[-5:-2]`: 음수를 사용하면 문자열의 끝에서부터 인덱스를 계산합니다.
* **문자열 내장 함수:**
    * `upper()`, `lower()`: 대소문자 변환
    * `strip()`: 문자열 양끝의 공백 제거
    * `replace("a", "b")`: 특정 문자를 다른 문자로 치환 (원본은 변경되지 않음)
    * `split(",")`: 특정 구분자를 기준으로 문자열을 쪼개어 리스트로 반환합니다.

## 2. 객체지향 프로그래밍 (Classes & OOP)
* **클래스와 객체:** `class` 키워드로 설계도(클래스)를 만들고, `p1 = Person(...)` 처럼 객체(인스턴스)를 생성합니다.
* **생성자 (`__init__`):** 객체가 생성될 때 자동으로 호출되는 초기화 메서드입니다. 첫 번째 매개변수로 항상 자기 자신을 의미하는 `self`를 받습니다.
* **메서드 (Method):** 클래스 내부에 정의된 함수입니다. `self.name`과 같이 객체의 속성에 접근할 수 있으며, `self.greet()` 처럼 클래스 내부의 다른 메서드를 호출할 수도 있습니다.

## 3. 데이터 시각화 (Matplotlib)
* **기본 차트 그리기:** `matplotlib.pyplot`을 `plt`로 임포트하여 사용합니다.
* **포맷 문자열 (Format String):** `plt.plot(ypoints, '*:r')`와 같이 짧은 문자열로 마커 모양(별표 `*`), 선 스타일(점선 `:`), 색상(빨간색 `r`)을 한 번에 지정할 수 있습니다.
* **출력:** `plt.show()`를 통해 그려진 그래프를 화면에 출력합니다.

## 4. 웹 대시보드 및 UI (Streamlit)
* **데이터프레임 출력:** `st.dataframe()`을 통해 Pandas 데이터프레임을 웹에 표출할 수 있으며, `thirdframe.style.highlight_max(axis=0)`처럼 최대값 강조 등 스타일을 적용할 수 있습니다.
* **텍스트 및 마크다운 표출:**
    * `st.markdown()`: 마크다운 문법(굵게, 기울임, 색상 텍스트, 이모지 등)을 렌더링합니다.
    * `st.caption()`: 작고 연한 설명용 텍스트를 출력합니다.
    * `st.code()`: 코드 블록 형식으로 텍스트를 보여줍니다.
* **UI 컴포넌트:**
    * `st.slider()`: 범위나 값을 선택할 수 있는 슬라이더를 제공합니다.
    * `st.divider()`: 가로 구분선을 삽입합니다.
    * `st.badge()`: 강조용 배지를 삽입할 수 있습니다.
* **코드 에코 (`st.echo`):** `with st.echo():` 블록 안에 코드를 작성하면, 실행 결과뿐만 아니라 작성된 코드 자체도 웹 페이지에 함께 표출되어 튜토리얼을 만들 때 유용합니다.
