## 2. ch05 — 프롬프트 템플릿과 부분 변수

### 2.1 `PromptTemplate` 만드는 두 가지 방법

```python
# ① from_template : 템플릿 문자열에서 {변수}를 자동 추출
prompt = PromptTemplate.from_template("{country}의 수도는 어디인가요 ?")

# ② 생성자 : template, input_variables를 직접 명시
prompt = PromptTemplate(
    template="{country}의 수도는 어디인가요 ?",
    input_variables=["country"],
)
```

- 두 방식 결과는 동일하다. `from_template`이 더 간단해서 실무에서 주로 쓴다.
- `prompt.format(country="대한민국")` → `'대한민국의 수도는 어디인가요 ?'` (**완성된 문자열**을 돌려줌).
- ⚠️ 노트북에서 `prompt = prompt.format(...)`처럼 **같은 변수명에 다시 대입**하면 템플릿 객체가 문자열로 바뀐다. 이후 `prompt | llm`을 쓰려면 템플릿을 다시 만들어야 한다 (실제로 바로 다음 셀에서 다시 정의).

### 2.2 체인에 연결하기

```python
chain = prompt | llm
chain.invoke("대한민국").content     # '대한민국의 수도는 서울입니다.'
```

- 변수가 **하나뿐이면** 딕셔너리 대신 값만(`"대한민국"`) 넘겨도 된다.

### 2.3 부분 변수 (partial variables)

여러 변수 중 **일부를 미리 채워 두는** 기능.

```python
template = "{country1} 과 {country2} 의 수도는 각각 어디인가요 ?"

# 방법 1) 생성 시점에 partial_variables 로 지정
prompt = PromptTemplate(
    template=template,
    input_variables=["country1"],                 # 나중에 입력받을 변수만 적는다
    partial_variables={"country2": "미국"},        # 미리 고정
)
prompt.format(country1="대한민국")   # '대한민국 과 미국 의 수도는 각각 어디인가요 ?'

# 방법 2) 만들어진 템플릿에서 .partial() 로 값 덮어쓰기 → 새 템플릿 반환
prompt_partial = prompt.partial(country2="캐나다")
prompt_partial.format(country1="대한민국")   # '... 캐나다 ...'
```

- `input_variables`에는 **아직 안 채운 변수만** 적는다. (`partial_variables`에 있는 건 제외)
- `.partial()`은 원본을 바꾸지 않고 **새 템플릿을 반환**한다.
- 체인에서도 사용 가능:
  - `chain.invoke("대한민국")` → 남은 변수 1개라 값만 넘겨도 OK → 캐나다 결과
  - `chain.invoke({"country1": "대한민국", "country2": "호주"})` → **invoke 시점에 partial 값을 덮어쓸 수 있다** → 호주 결과

## 3. ch05_2 — 함수로 채우는 부분 변수

값이 **호출할 때마다 달라져야 하는 경우**(오늘 날짜 등)에는 값 대신 **함수**를 넣는다.

```python
def get_today():
    return datetime.now().strftime("%B %d")     # 'September 15'

prompt = PromptTemplate(
    template="오늘의 날짜는 {today} 입니다. 오늘이 생일인 유명인 {n}명을 나열해 주세요. 생년월일을 표기해 주세요",
    input_variables=["n"],
    partial_variables={"today": get_today},      # 함수 자체를 넘김 (괄호 X)
)
prompt.format(n=3)
```

- 함수를 넘기면 **`format()`/`invoke()`가 실행되는 순간마다 함수가 호출**된다. 값(`get_today()`)을 넘기면 템플릿 생성 시각의 날짜로 굳어버린다.
- 인자 없는 함수여야 한다 (`def get_today():`).
- `chain.invoke(3)` → 오늘 날짜(9월 15일) 자동 반영.
- `chain.invoke({"today": "Jan 02", "n": 3})` → **수동으로 값을 주면 함수 대신 그 값이 우선**한다 (1월 2일 생일 결과).
- 비교: ex_0914 ch04_7에서는 같은 일을 `{"today": RunnableLambda(get_today), ...} | prompt`로 체인 앞단에서 처리했다. 여기서는 **템플릿 안에서** 해결하는 방식.

## 4. ch05_3 — YAML 파일에서 프롬프트 불러오기

프롬프트를 코드에서 분리해 **파일로 관리**하는 방법이다. 수정할 때 코드를 건드리지 않아도 되고, 재사용·공유가 쉽다.

### 4.1 YAML 파일

`fruit_color.yaml` (한 줄)

```yaml
_type: "prompt"
template: "{fruit}의 색깔이 뭐야?"
input_variables: ["fruit"]
```

`capital.yaml` (여러 줄 — `|` 블록)

```yaml
_type: "prompt"
template: |
  {country}의 수도에 대해서 알려주세요.
  수도의 특징을 다음의 양식에 맞게 정리해 주세요.
  300자 내외로 작성해 주세요.
  한글로 작성해 주세요.
  ----
  [양식]
  1. 면적
  2. 인구
  3. 역사적 장소
  4. 특산품

  #Answer:
input_variables: ["country"]
```

- `_type: "prompt"`: 이 파일이 `PromptTemplate`임을 알리는 필수 키.
- `template: |` : 줄바꿈이 그대로 유지되는 여러 줄 문자열 (YAML 블록 스칼라).
- 노트북 안 주석에는 `input_variable`로 적혀 있지만 실제 키 이름은 **`input_variables`** (복수형).

### 4.2 로드하기

```python
from langchain_core.prompts import load_prompt

prompt  = load_prompt("fruit_color.yaml", encoding="utf-8")
prompt.format(fruit="사과")            # '사과의 색깔이 뭐야?'

prompt2 = load_prompt("capital.yaml", encoding="utf-8")
chain = prompt2 | ChatOpenAI(model="gpt-4o-mini", temperature=0) | StrOutputParser()
stream_response(chain.stream({"country": "대한민국"}))
```

- **`encoding="utf-8"`이 중요**: 한글 YAML을 윈도우에서 읽을 때 지정하지 않으면 기본 인코딩(cp949) 때문에 오류가 날 수 있다.
- 로드한 객체는 일반 `PromptTemplate`과 똑같이 `format`, `|` 체인 연결이 된다.
- 프롬프트에 **양식([양식] 1~4번)과 분량(300자)을 지정**해서 답변 형태를 통제하는 프롬프트 작성 예시이기도 하다.

## 5. ch05_4 — `ChatPromptTemplate`

채팅 모델은 문자열 하나가 아니라 **역할이 붙은 메시지 목록**을 받는다. 이를 만들어 주는 템플릿이 `ChatPromptTemplate`.

### 5.1 `from_template` — 사용자(Human) 메시지 한 개

```python
chat_prompt = ChatPromptTemplate.from_template("{country}의 수도는 어디인가요 ?")
chat_prompt.format(country="대한민국")     # 'Human: 대한민국의 수도는 어디인가요 ?'
```

- 내부적으로 `HumanMessagePromptTemplate` 하나를 가진 형태.

### 5.2 `from_messages` — 역할별 메시지 목록

```python
chat_template = ChatPromptTemplate.from_messages([
    ("system", "당신은 친절한 AI 어시스턴트 입니다. 당신의 이름은 {name} 입니다."),
    ("human",  "반가워요 !"),
    ("ai",     "안녕하세요! 무엇을 도와드릴까요 ?"),
    ("human",  "{user_input}"),
])
```

| 역할 | 의미 |
|---|---|
| `system` | 모델의 역할·성격·규칙을 지시 |
| `human` | 사용자 발화 |
| `ai` | 모델의 이전 답변 (대화 맥락 / 예시로 활용) |

### 5.3 값 채우기와 호출

```python
messages = chat_template.format_messages(name="테디", user_input="당신의 이름은 무엇입니까 ? ")
# [SystemMessage(...), HumanMessage(...), AIMessage(...), HumanMessage(...)]

llm.invoke(messages).content            # '제 이름은 테디입니다. ...'

chain = chat_template | llm
chain.invoke({"name": "Teddy", "user_input": "당신의 이름은 무엇입니가?"}).content
```

- `format()` → **문자열**, `format_messages()` → **메시지 객체 리스트** (`llm.invoke`에 바로 전달 가능).
- 체인으로 쓰면 `format_messages`를 직접 부를 필요 없이 딕셔너리만 `invoke`하면 된다.
- 시스템 메시지의 `{name}`처럼 **어느 메시지에든 변수**를 넣을 수 있다.

## 6. ch05_5 — `MessagesPlaceholder`

**메시지 목록 전체를 변수처럼** 끼워 넣는 자리표시자. 대화 기록이 몇 개인지 미리 알 수 없을 때 사용한다.

```python
chat_prompt = ChatPromptTemplate.from_messages([
    ("system", "당신은 요약 전문 AI 어시스턴트입니다. 당신의 임무는 주요 키워드로 대화를 요약하는 것입니다."),
    MessagesPlaceholder(variable_name="conversation"),          # ← 여기에 대화 목록이 통째로 들어감
    ("human", "지금까지의 대화를 {word_count} 단어로 요약합니다."),
])
```

값 전달

```python
chain = chat_prompt | llm | StrOutputParser()
chain.invoke({
    "word_count": 5,
    "conversation": [
        ("human", "안녕하세요! 저는 오늘 새로 입사한 테디입니다. 만나서 반갑습니다."),
        ("ai",    "반가워요! 앞으로 잘 부탁드립니다."),
    ],
})
# '테디 새로 입사한 것을 환영합니다.'
```

- 템플릿에서 확인되는 입력 변수: `conversation`(메시지 리스트), `word_count`.
- `format()` 결과는 `System: ... / Human: ... / AI: ... / Human: ...` 순서로 펼쳐진다. 즉 **placeholder 위치에 대화가 그대로 삽입**된다.
- 쓰임새: 챗봇의 **대화 기록(memory)** 주입, 요약/번역 등 "이전 대화를 참고해서 처리"하는 프롬프트.
- 구조가 "시스템 지시 → (가변 길이 기록) → 마지막 요청" 순서인 점이 포인트.

## 7. ch05_6 — 퓨샷 프롬프트 (`FewShotPromptTemplate`)

프롬프트에 **정답 예시 몇 개를 함께 보여줘서** 답하는 방식/형식을 모델에게 가르치는 기법.

### 7.1 예시 데이터와 예시 서식

```python
examples = [{
    "question": "스티브 잡스와 아인슈타인 중 누가 더 오래 살았나요 ?",
    "answer": """이 질문에 추가 질문이 필요한가요: 예.
                추가 질문 : 스티브 잡스는 몇 살에 사망했나요 ?
                중간 답변 : 스티브 잡스는 56세에 사망했습니다.
                추가 질문 : 아인슈타인은 몇 살에 사망했나요
                중간 답변 : 아인슈타인은 76세에 사망했습니다.
                최종 답변은 : 아인슈타인"""
}]

example_prompt = PromptTemplate.from_template("Question:\n{question}\nAnswer:\n{answer}")
example_prompt.format(**examples[0])     # 딕셔너리를 키워드 인자로 풀어서 전달
```

- 이 예시는 복잡한 질문을 **"추가 질문 → 중간 답변"으로 쪼개서 푸는 방식**(Self-ask 스타일)을 보여준다.
- `example_prompt`는 **예시 1개를 어떻게 출력할지**를 정하는 템플릿.

### 7.2 `FewShotPromptTemplate` 조립

```python
prompt = FewShotPromptTemplate(
    examples=examples,                 # 예시 목록
    example_prompt=example_prompt,     # 예시 1개의 서식
    suffix="Question:\n{question}\nAnswer:",   # 예시들 뒤에 붙는, 실제 질문 부분
    input_variables=["question"],      # suffix에서 사용하는 변수
)
prompt.format(question="Google이 창립된 연도에 Bill Gates의 나이는 몇 살인가요?")
```

최종 프롬프트 구조: `[예시 1] + [예시 2] + ... + [suffix(실제 질문)]`

| 인자 | 역할 |
|---|---|
| `examples` | 예시 딕셔너리 리스트 |
| `example_prompt` | 예시를 문자열로 바꾸는 템플릿 |
| `prefix` (여기선 미사용) | 예시 앞에 붙는 지시문 |
| `suffix` | 예시 뒤에 붙는 실제 입력 부분 |
| `input_variables` | suffix(/prefix)에서 쓰는 변수 |

### 7.3 실행 방법 두 가지

```python
# ① 완성된 문자열을 llm에 직접 전달
llm.stream(prompt.format(question=question))

# ② 체인으로 연결
chain = prompt | llm | StrOutputParser()
chain.stream({"question": "..."})
```

- 실행 결과가 **①은 예시처럼 "추가 질문/중간 답변/최종 답변" 형식**으로 나왔고, **②는 한 줄 답변**만 나왔다. 프롬프트는 사실상 같지만 `ChatOpenAI()`의 기본 temperature가 높아 **출력이 매번 달라질 수 있다**. 형식을 강하게 고정하려면 지시를 더 명확히 하거나 `temperature=0`을 쓴다.
- 예시 `answer`를 `"""` 안에서 들여쓰기하면 **공백이 그대로 프롬프트에 들어간다** (출력에서 줄마다 앞 공백이 보인다). 다음 노트북에서는 왼쪽 정렬로 고쳤다.

## 8. ch05_7 — 예제 선택기 (Example Selector)

예시가 많을 때 전부 넣으면 토큰 낭비다. **입력과 가장 비슷한 예시만 골라서** 넣는 것이 예제 선택기.

### 8.1 구성 요소

```python
from langchain_core.example_selectors import (
    MaxMarginalRelevanceExampleSelector,   # (import만 됨, 실제 사용 X) 유사도 + 다양성
    SemanticSimilarityExampleSelector,     # 의미 유사도 기반
)
from langchain_openai import OpenAIEmbeddings   # 텍스트 → 벡터(임베딩)
from langchain_chroma import Chroma             # 벡터 DB   (%pip install langchain_chroma)
```

### 8.2 선택기 생성

예시 4개(스티브 잡스/아인슈타인, 네이버 창립자, 율곡 이이 어머니, 올드보이·기생충)를 준비하고:

```python
example_selector = SemanticSimilarityExampleSelector.from_examples(
    examples,               # 예시 목록
    OpenAIEmbeddings(),     # 임베딩 모델
    Chroma,                 # 벡터 DB 클래스
    k=1,                    # 가장 유사한 예시 1개만 선택
)
```

동작 원리: 예시를 임베딩해 Chroma에 저장 → 입력 질문도 임베딩 → **의미가 가장 가까운 예시 k개를 검색**.

### 8.3 선택 결과 확인

```python
example_selector.select_examples({"question": "Google이 창립된 연도에 Bill Gates의 나이는 몇 살인가요?"})
```

- "Google 창립 연도 + 빌 게이츠 나이"와 가장 비슷한 예시로 **"네이버의 창립자는 언제 태어났나요?"**(창립자의 생년 관련)가 뽑혔다.
- `select_examples`의 입력은 **딕셔너리**이고, 키는 예시 데이터의 키(`question`)와 맞춘다.

### 8.4 `FewShotPromptTemplate`에 연결

```python
prompt = FewShotPromptTemplate(
    example_selector=example_selector,     # examples= 대신 example_selector=
    example_prompt=example_prompt,
    suffix="Question:\n{question}\nAnswer:",
    input_variables=["question"],
)
chain = prompt | llm
```

- ch05_6과 차이는 `examples=` 대신 `example_selector=`를 쓴다는 것 하나뿐. 이제 프롬프트에는 **선택된 예시만** 들어간다.
- 참고할 점
  - 코드 상단의 `chroma = Chroma("example_selector", OpenAIEmbeddings())` 객체는 이후 쓰이지 않는다 (`from_examples`에는 **클래스** `Chroma`를 넘김).
  - 출력에 찍힌 네이버 예시의 answer 문구가 현재 코드의 `examples`와 다르다 → 셀 출력이 예시를 수정하기 전 실행 결과일 가능성이 있다. **예시를 고친 뒤에는 선택기를 다시 만들어야** 반영된다 (벡터DB에 이미 저장된 상태이기 때문).
  - 마지막 답변의 "43살"은 사실과 다르다 (Google 창립 1998년 9월, 빌 게이츠 1955년 10월생 → 42세). 예시 1개만 참고했고 모델 성능이 낮아 **정답 검증은 별개**라는 점을 보여 준다.

## 9. ch05_8 — `FewShotChatMessagePromptTemplate` + 커스텀 선택기

ch05_6·7의 퓨샷은 예시를 **하나의 문자열**로 이어붙였다. 여기서는 예시를 **human/ai 메시지 쌍**으로 만들어 채팅 형식으로 넣는다.

### 9.1 예시 데이터

키가 3개(`instruction`, `input`, `answer`)이고 작업 종류가 서로 다른 3개 예시: **회의록 작성 / 문서 요약 / 문장 교정**.

### 9.2 선택기 + 채팅형 퓨샷 템플릿

```python
example_prompt = ChatPromptTemplate.from_messages([
    ("human", "{instruction}:\n{input}"),     # 예시 1개 = 사용자 메시지
    ("ai",    "{answer}"),                    #            + AI 답변 메시지
])

example_selector = SemanticSimilarityExampleSelector.from_examples(
    examples, OpenAIEmbeddings(), chroma, k=1
)

few_shot_prompt = FewShotChatMessagePromptTemplate(
    example_selector=example_selector,
    example_prompt=example_prompt,
)
```

### 9.3 최종 프롬프트 조립

```python
final_prompt = ChatPromptTemplate.from_messages([
    ("system", "You are a helpful assistant."),
    few_shot_prompt,                               # ← 선택된 예시가 human/ai 메시지로 펼쳐짐
    ("human", "{instruction}\n{input}"),           # 실제 질문
])

chain = final_prompt | llm
stream_response(chain.stream({"instruction": "회의록을 작성해 주세요", "input": "2023년 12월 26일 ABC 기술 회사 ... 회의 ..."}))
```

- 메시지 구조: `system → (예시 human/ai 쌍) → 실제 human`.
- 질문이 "회의록을 작성해 주세요 + 회의 내용"이라 **회의록 예시가 선택**되었고, 출력도 예시와 같은 형식(회의록: … / 일시 / 장소 / 참석자 / 번호 목록)으로 나왔다. 퓨샷이 **출력 형식을 학습시키는 효과**가 확인된다.
- `ChatPromptTemplate` 안에 `FewShotChatMessagePromptTemplate` 객체를 **그대로 리스트 원소로** 넣을 수 있다.
- 여기서는 `from_examples(..., chroma, k=1)`에 **인스턴스** `chroma`를 넘겼다 (ch05_7은 클래스). 동작은 하지만 관례는 클래스 전달.

### 9.4 목적에 맞는 예제 선택기 (`CustomExampleSelector`)

기본 선택기는 입력 딕셔너리의 **모든 값**을 합쳐 유사도를 구한다. 그런데 `input`은 길고 내용이 제각각이라 판단을 흐린다. `instruction`만 보고 고르고 싶을 때 커스텀 선택기를 쓴다.

```python
from langchain_teddynote.prompts import CustomExampleSelector

custom_selector = CustomExampleSelector(examples, OpenAIEmbeddings())
custom_selector.select_examples({"instruction": "다음 문장으로 회의록을 작성해 주세요"})
# → 회의록 예시가 선택됨
```

- `input`은 무시하고 **`instruction` 값만으로** 유사도를 계산한다 (노트북 주석 설명).
- 이 클래스는 `langchain_teddynote`가 제공하는 것으로, 직접 만들려면 `BaseExampleSelector`를 상속해 `add_example`, `select_examples`를 구현하면 된다.

### 9.5 ⚠️ 코드에서 놓치기 쉬운 부분 (버그로 보이는 곳)

```python
# ① 오타: 변수명이 {intruction} (n 빠짐) → 예시 키 'instruction'과 불일치
example_prompt = ChatPromptTemplate.from_messages([
    ("human", "{intruction}:\n{input}"),
    ("ai", "{answer}"),
])

custom_fewshot_prompt = FewShotChatMessagePromptTemplate(
    example_selector=custom_selector, example_prompt=example_prompt,
)

# ② custom_prompt 조립 시 custom_fewshot_prompt가 아니라 기존 few_shot_prompt를 넣음
custom_prompt = ChatPromptTemplate.from_messages([
    ("system", "You are a helpful assistant."),
    few_shot_prompt,                       # ← custom_fewshot_prompt 여야 커스텀 선택기가 적용됨
    ("human", "{instruction}\n{input}"),
])
```

- ①의 오타 때문에 `custom_fewshot_prompt`를 실제로 쓰면 `{intruction}` 변수를 못 찾아 오류가 난다.
- ②처럼 `few_shot_prompt`를 넣었기 때문에 **결과적으로 커스텀 선택기는 실제로는 사용되지 않았다**. 그래서 출력이 앞의 결과와 비슷하게 나온 것. (회의록 예시가 어차피 가장 유사해서 티가 안 난다.)
- 고치려면 `{instruction}`으로 수정하고, `custom_prompt`에 `custom_fewshot_prompt`를 넣는다.

### 9.6 환경 문제 디버깅 흔적

노트북 중간에 `import onnxruntime` 셀이 **커널 충돌**로 끝났고, 이어서 `numpy.__version__`(2.5.3)을 확인한 셀이 있다. Chroma가 내부적으로 `onnxruntime`/`numpy`에 의존해서, 설치·버전 문제를 추적하던 기록이다. 코드 학습 내용은 아니지만 **"Chroma import 시 커널이 죽으면 onnxruntime/numpy 버전을 의심"**하는 힌트로 남겨 둘 만하다.

## 10. 개념 한 장 요약

### 프롬프트 템플릿 종류

| 클래스 | 결과물 | 언제 |
|---|---|---|
| `PromptTemplate` | 문자열 | 단순 텍스트 프롬프트 |
| `ChatPromptTemplate` | 메시지 리스트 (system/human/ai) | 채팅 모델, 역할 구분이 필요할 때 |
| `MessagesPlaceholder` | (ChatPromptTemplate 안의) 가변 길이 메시지 | 대화 기록 주입 |
| `FewShotPromptTemplate` | 문자열 (예시 + 질문) | 예시를 텍스트로 나열 |
| `FewShotChatMessagePromptTemplate` | human/ai 메시지 쌍 | 예시를 채팅 메시지로 나열 |

### 변수를 채우는 방법

| 방법 | 예 | 특징 |
|---|---|---|
| 호출 시 입력 | `chain.invoke({"country": ...})` | 기본 |
| `partial_variables` (값) | `{"country2": "미국"}` | 고정값 미리 지정, invoke에서 덮어쓰기 가능 |
| `.partial()` | `prompt.partial(country2="캐나다")` | 기존 템플릿에서 새 템플릿 파생 |
| `partial_variables` (함수) | `{"today": get_today}` | **호출 시마다** 계산 (날짜 등) |

### 퓨샷 흐름

```
examples ──(선택기: 유사한 k개만)──▶ example_prompt로 서식화 ──▶ [예시들] + [suffix/실제 질문] ──▶ llm
```

### 파일 관리

```
prompt.yaml ──load_prompt(path, encoding="utf-8")──▶ PromptTemplate ──▶ prompt | llm
```

## 11. 공부하며 기억할 함정

1. `prompt = prompt.format(...)`처럼 **템플릿 변수에 문자열을 덮어쓰지 말 것** (체인에 연결 불가).
2. `partial_variables`에 함수를 넣을 땐 **호출하지 않고 함수 자체**를 넘긴다 (`get_today`, not `get_today()`).
3. `input_variables`에는 **partial로 채운 변수를 제외**한 것만 적는다.
4. `load_prompt`는 한글 파일이면 `encoding="utf-8"`, YAML 키는 `input_variables`(복수형).
5. `format()`은 문자열, `format_messages()`는 메시지 객체 — 채팅 모델에는 후자(또는 체인)를 쓴다.
6. 퓨샷 예시의 **들여쓰기 공백이 그대로 프롬프트에 들어간다**. 삼중따옴표 문자열은 왼쪽 정렬로 쓴다.
7. 예제 선택기는 **벡터 DB에 예시를 저장**한다. 예시를 수정했으면 선택기를 다시 만들어야 반영된다.
8. 변수명 오타(`{intruction}`)와 **엉뚱한 객체 사용**(`few_shot_prompt` vs `custom_fewshot_prompt`)은 오류 없이 지나가기도 한다 → 선택된 예시를 `select_examples`로 직접 출력해 확인하는 습관을 들이자.
9. `ChatOpenAI()` 기본값은 temperature가 높고 구형 모델이라 결과가 흔들린다. 재현성이 필요하면 `model`, `temperature=0`을 명시한다.
10. LLM이 낸 사실 정보(빌 게이츠 나이 등)는 틀릴 수 있다. 퓨샷은 **형식**을 잡아 주는 데 강하고, **정확성**을 보장하지는 않는다.
